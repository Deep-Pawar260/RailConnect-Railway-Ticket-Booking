# Bharat RailConnect V6 — Advanced Railway Frontend Demo

React + JavaScript + HTML + CSS only.

## Included
- Live train tracker
- Interactive India rail map
- QR-style digital ticket
- Visual coach/seat selection
- Platform finder
- Mobile-responsive ticket
- Food ordering/cart
- Travel alerts
- Admin analytics
- Hindi/English language switch
- Journey planner
- Train comparison
- Appearance Studio: 6 color presets, custom primary/secondary/accent/background/text colors, dark/light mode, compact/comfortable density, font-size control
- 3 built-in background styles + custom background image upload
- Generic government-inspired emblem/logo (not an official government logo)
- LocalStorage demo state

## Run
```bash
npm install
npm run dev
```
Open http://localhost:5173/

This is a portfolio/demo application. It is not an official government or railway website and does not perform real bookings or payments.
